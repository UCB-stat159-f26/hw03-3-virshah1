# HW3 Personal Reflection

This assignment gave me experience creating a publicly available Python package rather than simply writing code for my own analysis. I learned how to organize functions into a reusable package, make it installable directly from GitHub, and ensure that other users could access its functionality without needing to understand the underlying code.

One challenge was the requirement to keep every function under 20 lines. This forced me to break larger tasks into smaller, more focused functions. Although this initially made the assignment more complicated, it ultimately made my code easier to organize, test, and troubleshoot.

I also made significantly more Git commits than in previous assignments, since last time I was told that I was committing too infrequently. Instead of committing large amounts of work at once, I made smaller commits after completing individual features, fixes, or tests. This helped me better understand the importance of maintaining a clear and meaningful project history.

Overall, HW3 taught me to think beyond simply getting my code to work and focus more on writing reusable, maintainable, and well-documented software.
